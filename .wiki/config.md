# gleipnir-ipc Topic Guide

This wiki tracks the Gleipnir IPC implementation — a consensus-anchored
provenance chain using SMT-based inclusion proofs, gRPC API, and
containerized test infrastructure.

## Structure

- `wiki/references/` — protocol specs, conformance results, architecture decisions
- `wiki/concepts/` — design concepts (SMT, VRF, quorum, lambda1)
- `raw/` — ingested external sources (papers, notes, CLIs)
- `output/` — collected artifacts, reports, research outputs
- `inventory/` — tracked items, candidates, corpus metadata
